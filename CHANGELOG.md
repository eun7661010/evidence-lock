## [0.1.0] - 2026-08-21

### Added

- Strict `evidence-lock/receipt/v1` JSON Schema.
- Standard-library Python API for file and directory evidence snapshots.
- `create`, `review`, `verify`, and `schema` commands.
- Required source, artifact, and policy hash groups.
- Human and AI reviewer labels with approved or rejected decisions.
- Approved, pending, rejected, stale, and invalid verification states.
- Portable relative paths, symlink rejection, output overlap checks, and exclusive writes.
- Synthetic example receipts and cross-platform CI.
